# Real-Estatae Management (ITI-GraduationProject)

## 📌 Overview
With the rapid growth of residential units, many tenants living in the same building—or even the same unit—often don’t know each other.  
Our project **Livana** was created to solve this problem by building connected residential communities and simplifying property management.

Livana is a platform that connects residents, landlords, and local service providers in one place, making everyday life easier and more organized.


### 🏘 Community for Each Residential Unit
- Dedicated community for each building or unit
- Residents can share ideas, feedback, announcements, and suggestions
- Real-time communication between residents

### 🛒 Support for Local Services
- Local service providers (supermarkets, gyms, clinics, etc.) can promote their services
- Residents can easily discover nearby services within their community

### 💰 Simplified Rent Collection
- Landlords can collect rent in just a few steps
- Tenants can pay rent conveniently and securely

### 🏠 Property Listing & Booking
- Landlords can advertise available units
- Visitors can browse listings and schedule viewings through the platform

---

## 🎯 Project Goals
- Connect residents within the same residential units
- Support local businesses and services
- Simplify rental and property management for landlords and tenants

## 🛠️ Technologies Used 
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- JWT Authentication
- RESTful API
- SignalR (Real-time communication)
- Hangfire (Background jobs and scheduling)
